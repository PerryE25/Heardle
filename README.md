# Heardle

## Team Members
Jeremiah Franklin, Victor Sanchez, Haroon Memon, Perry Ehimuh

## Name of Project
Heardle

## Dependencies
- Xcode
- Swift
- Spotify iOS XC Framework

## Special Instructions
• Before running the project, download the Spotify iOS XC Framework from GitHub and add it to the project under:
  Project Settings → Target → Frameworks, Libraries, and Embedded Content.

• If the Spotify iOS XC Framework already exists in the project, remove it first and re-add the downloaded framework to ensure a clean build.

• After adding the framework, clean and build the project before running.

• Run the application using an iPhone simulator.
